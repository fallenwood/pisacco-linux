# Picasso Linux

[English](README.md) | 简体中文

面向 **Redmi K30 5G（`picasso`，SM7250 / Snapdragon 765G）** 的实验性 Linux
移植项目，结合 Fedora Server 44 aarch64 用户空间、默认 Linux 7.3.1、
保留用于救援的 Linux 6.18 LTS 与本地硬件适配。

项目包含内核补丁、设备树、救援 initramfs、启动镜像与根文件系统构建工具，
以及受保护的显示、Wi-Fi 和电源实验工具。**不是完整手机系统或稳定成品 ROM**，
不适合日常手机或无人值守服务器用途。

## 功能状态

“已实现”仅表示在笔记记录的范围内实际运行过，不代表完整硬件验收或实时健康状态。
部分实现、未解决和未验证的项目均不算完成。

| 功能 | 状态 | 范围或限制 |
| --- | --- | --- |
| Fedora Server 启动与 systemd | 已实现 | 原生 Fedora 用户空间与初始化系统。 |
| 持久 XFS 根文件系统 | 已实现 | 已完成安装、正常重启和文件持久化验证。 |
| 默认 Linux 7.3.1 与 6.18 救援 | 已实现 | 已验证默认原生启动及屏幕/Wi-Fi 自启动，保留已验证的 6.18 救援内核。 |
| CPU 与 UFS 存储 | 已实现 | CPU 启动、调频与存储访问；不代表完整内存或存储耐久验收。 |
| USB 网络、串口控制台与 SSH | 已实现 | USB NCM/ACM 与 SSH 公钥登录。 |
| 防火墙与 ZRAM | 已实现 | 已实现并验证包过滤与压缩交换。 |
| 文字控制台与背光控制 | 已实现 | 使用继承的 framebuffer，提供原生 tty1、空闲关灯与音量上亮屏。 |
| 2.4 GHz Wi-Fi | 部分实现 | WPA2/CCMP、DHCP、DNS 与 HTTPS 已通过；历史掉线问题仍未解决。 |
| 启动时 Wi-Fi 优先连接与回退 | 部分实现 | 7.3.1 已验证冷启动自动连接/回退及局域网 SSH；首选 5 GHz 链路仍未解决。 |
| Wi-Fi 掉线自动重连 | 未启用 | 最新服务不在掉线后自动重试连接。 |
| 5 GHz Wi-Fi | 未解决 | 已有连接尝试超时。 |
| Rootless Podman | 部分实现 | 7.3.1 已运行受限容器负载，广泛负载验收仍未完成。 |
| 原生 DSI 显示、GPU 与触摸 | 未实现 | framebuffer 文字控制台不等于完整原生图形栈。 |
| 蓝牙、音频、蜂窝与相机 | 不可用 | 尚未移植，或尚未验证为可用的设备功能。 |
| 电池、充电与电量计 | 不可用 | 遥测与安全充电尚未建立。 |
| 整机温控安全 | 未验证 | 已有运行期温度保护，但不代表完整温控或充电安全。 |
| 挂起与恢复 | 未实现 | 背光熄灭不等于整机休眠。 |
| 电源键关机 | 部分实现 | 历史输入与关机失败尚未解决，7.3.1 电源服务保持禁用。 |
| 关机后保持断电 | 未解决 | 已出现关机后自行启动。 |
| SELinux 强制执行 | 未启用 | 已记录的内核实际为 permissive，而非 enforcing。 |
| 长期稳定性 | 未验证 | 尚未完成日常使用、耐久或无人值守运行验收。 |
